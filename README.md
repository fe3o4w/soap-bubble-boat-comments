# 肥皂泡小船 · 评论

[访问博客](https://soap-bubble-boat.pages.dev/) · [查看公开评论](https://github.com/fe3o4w/soap-bubble-boat-comments/discussions)

本仓库保存博客文章的公开评论，使用 giscus 与 GitHub Discussions。博客源码、草稿、部署令牌和私有备份存放在单独的私有仓库中。

登录 GitHub 后可发表评论、回复和表情回应。每篇文章使用固定的 `post:文章标识` 关联讨论；改标题和网站域名不会改变这种关联。

## 管理与删除

博主 fe3o4w 拥有本仓库管理员权限。打开对应讨论，在需要删除的留言右上角点击“⋯”→ Delete → 确认，即可删除。也可以隐藏留言、锁定讨论或屏蔽用户。

文章底部提供前往当前讨论的入口。评论通过 giscus 与 GitHub 同步，删除后刷新博客评论区即可看到结果。

## 备份

私有源码仓库中的工作流会在每次源码推送及每日中国标准时间 03:17 导出本仓库 Announcements 分类的讨论、评论和回复，保存 JSON 与 SHA-256 校验文件，私有快照保留 90 天。讨论和回复按游标分页完整读取。

Git clone 不会包含 Discussions 数据。删除线上留言后，历史快照可能仍保留该留言，直到快照过期或由博主主动删除。恢复导出数据时可保留原始署名和时间说明；重新发布的留言归恢复操作所用账号，原始账号身份、时间和反应无法直接重建。
